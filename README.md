# levihenstrom.github.io

My portfolio: case studies of the systems I build. Live at **https://levihenstrom.github.io**.

Plain HTML, CSS, and JavaScript. No build step and no dependencies, served by GitHub Pages.

## Edit locally

Open `index.html` in a browser, or run a quick local server:

```bash
python3 -m http.server 8000   # then visit http://localhost:8000
```

## Files

- `index.html`: all content (case studies, experience, skills)
- `style.css`: light/dark theme tokens and layout
- `script.js`: theme toggle and small UI touches
- `favicon.svg`
